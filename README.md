# The xPack GCC

A standalone, cross-platform (Windows, GNU/Linux) binary
distribution of GCC,
intended for reproducible builds.

## Project documentation

For information on how to install and use this project, please refer to the
[project website](https://xpack-dev-tools.github.io/gcc-xpack/).

## Project source

The source code of the current release is available on
[GitHub tag v13.4.0-1.1 tree](https://github.com/xpack-dev-tools/gcc-xpack/tree/v13.4.0-1.1).
